# БСО — приложение выездного мастера

Устанавливаемое веб-приложение для подготовки предварительных смет и фактических бланков обслуживания.

## Установка на телефон

Откройте опубликованный адрес GitHub Pages на телефоне. В браузере выберите «Добавить на главный экран» или «Установить приложение». Для работы без интернета сначала откройте приложение онлайн.

При первом запуске импортируйте личный `rates.csv` в разделе «Мои цены». Личные расценки и данные заказов хранятся в локальном браузере на устройстве и не отправляются на сайт. Этот репозиторий содержит только пустые файлы каталога и примеров. Для переноса между телефонами используйте экспорт резервной копии внутри приложения.

## Публикация

Сайт публикуется GitHub Actions из корня репозитория при изменениях ветки `main`. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации, если ещё не выбран.
